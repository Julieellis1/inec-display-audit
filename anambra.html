Anambra is the third state audited, and the largest so far at 5,720 polling units. We read every polling unit on INEC's display portal for Anambra, all 21 local government areas and 326 wards, and compared the list with the June 2021 expansion list used for the 2023 election. The 2015 total for Anambra was 4,608. Comparing with 2015 would mix the official 2021 expansion in with any later change, so the test that matters is display against 2021. See the method page.

The 2021 locator did not always return the same name list twice. In 3 of the 21 LGAs the names attached to some codes changed between visits, even though the counts never changed. All versions are published in the workbook, and the LGA pages name the wards where the locator changed its list.

What the names show

17 LGAs match the display at every code. Orumba North differs at 1 of 253 codes, a single-letter spelling: OPOSITE on the collected lists, OPPOSITE on the recollection, at code 04-19-18-027. In Anambra West, Idemili North and Onitsha South the portals returned several different name lists for the same codes; all versions are in the workbook. Five first 2021 lists were withdrawn as collection errors after live spot rechecks and recollected: Ayamelum, Awka South, Dunukofia, Orumba North and Oyi now match the display at every code.

A shared name is a flag to put to INEC, not proof of duplication. The same school or hall can legitimately host several polling units, and the portal itself repeats venue names with different numerals.
