Ebonyi is the sixth state audited, at 2,946 polling units. We read every polling unit on INEC's display portal for Ebonyi, all 13 local government areas and 171 wards, and compared the list with the June 2021 expansion list used for the 2023 election. Comparing with 2015 would mix the official 2021 expansion in with any later change, so the test that matters is display against 2021. See the method page.

Both lists sit one below the announced total. The Resident Electoral Commissioner announced 2,947 units for Ebonyi in June 2021, but the locator list itself carries 2,946, and the display portal also shows 2,946. The difference of one is already on the locator side; the display side confirms it rather than adding a new discrepancy.

The portals did not always return the same name list twice. In one LGA the first 2021 run proved transient, and in one LGA the first display list proved transient, even though the counts never changed. All versions are published in the workbook, and the LGA pages name the codes where the lists changed.

What the names show

All 13 LGAs match the display at every code. Two lists were corrected after live rechecks proved the first collection transient: the display list for Ohaozara (1 code, a misread of UMUITUM as UMITUM) and the 2021 list for Ishielu (a whole-LGA recollection after the first run matched at only 24 of 243 codes). The withdrawn version is in the workbook. No LGA is left with an unsettled name verdict.

A shared name is a flag to put to INEC, not proof of duplication. The same school or hall can legitimately host several polling units, and the portal itself repeats venue names with different numerals.
