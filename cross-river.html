Cross River is the fourth state audited, at 3,281 polling units. We read every polling unit on INEC's display portal for Cross River, all 18 local government areas and 193 wards, and compared the list with the June 2021 expansion list used for the 2023 election. Comparing with 2015 would mix the official 2021 expansion in with any later change, so the test that matters is display against 2021. See the method page.

The portals did not always return the same name list twice. In 2 of the 18 LGAs the first 2021 run proved transient, and in 3 LGAs the first display list proved transient, even though the counts never changed. All versions are published in the workbook, and the LGA pages name the codes where the lists changed.

What the names show

All 18 LGAs match the display at every code. Five lists were corrected after live spot rechecks proved the first collection transient: the display lists for Abi (1 code), Akpabuyo (1 code) and Calabar Municipal (2 codes), and the 2021 lists for Calabar South and Obudu (whole-LGA recollections). The withdrawn versions are in the workbook. No LGA is left with an unsettled name verdict.

A shared name is a flag to put to INEC, not proof of duplication. The same school or hall can legitimately host several polling units, and the portal itself repeats venue names with different numerals.
