# INEC Display Audit

A citizen audit of the polling unit list on INEC's 2026 display portal,
compared unit by unit with the June 2021 list used for the 2023 election.

## Pages

- `index.html`: national home, hand-maintained from the Hark design supplied
  by the user (hero, findings, state tile map, method, principles, data).
  NOT generated by build_website.py. When a new state is added, update the
  state tile data, the progress ring and the "1 of 37" counts in it.
- `abia.html`: Abia state page (overview, findings, LGA table, search, data).
- `lga/<slug>.html`: one page per Abia LGA, with its full unit list, error
  checks, 2021 comparison and CSV downloads.
- `method.html`: the method, principles, flag rules and sources.
- `data/`: 17 display CSVs (recollected versions for Aba North, Aba South,
  Umuahia North), 17 June 2021 CSVs, and the full workbook
  (Abia-Display-Audit-2026-11-06-v41.xlsx).
- `assets/`: Hark design system (hark.css, hark-hero.css, hark.js) plus
  site.css (small site additions) and search.js (Abia unit search).

## Header and menu

Every page carries the same header: a sticky pill built by hark.js from the
page's sections (`section[data-nav]`), with the site brand linking home and
cross-page links to States and Method added when the page has no section
with that id. The brand and page links are a small customisation inside
assets/hark.js (marked "Site menu"), reading `data-root` on the header
("" at the root, "../" one level down).

## Headline result

Abia, 6 November 2026: display 4,062 = June 2021 4,062. Change 0 in every
LGA and every ward. Exact name repeats in 10 of 17 LGAs; missing numbers
only in Aba North (Ariaria Market 058, Eziama 057). Three 2021 name lists
are unreliable until recollected (Ohafia, Osisioma Ngwa, Umuahia South);
three differ sharply (Aba North, Aba South, Umuahia North).

## Rebuild

Run `python3 build_website.py` in
~/workspace/your_files/inec-display-audit/. It rebuilds abia.html,
method.html, the 17 LGA pages, assets/units.json and the data files.
index.html is not touched.
