# INEC Display Audit

A citizen audit of the polling unit list on INEC's 2026 display portal,
compared unit by unit with the June 2021 list used for the 2023 election.

## Pages

- `index.html`: home, hand-maintained (full-bleed hero, why, coverage teaser,
  principles). NOT generated by build_website.py.
- `findings.html`: Abia findings, hand-maintained (stats, charts, checklists,
  LGA table, units chart). NOT generated by build_website.py.
- `states.html`: coverage, hand-maintained (tile map, search, state list).
  NOT generated by build_website.py. When a new state is added, update the
  state tile data, the progress ring and the "1 of 37" counts in it.
- `data.html`: downloads, hand-maintained. NOT generated by build_website.py.
- `abia.html`: Abia state page (overview, findings, charts, LGA table, search, data).
  Charts are generated from the workbook by charts.py (paired bars, name
  repeats, name match), same visual language as findings.html.
- `lga/<slug>.html`: one page per Abia LGA, with its full unit list, error
  checks, 2021 comparison and CSV downloads.
- `method.html`: the method, principles, flag rules and sources.
- `data/`: 17 display CSVs (recollected versions for Aba North, Aba South,
  Umuahia North), 17 June 2021 CSVs, 9 variant CSVs (Ohafia 2, Osisioma
  Ngwa 2, Umuahia North 1, Aba North 1, Aba South 3), and the full workbook
  (Abia-Display-Audit-2026-11-06-v52.xlsx).
- `assets/`: Hark design system (hark.css, hark-hero.css, hark.js) plus
  site.css (site styles and the standard header/footer) and search.js
  (Abia unit search).

## Header and menu

Every page carries the same standard header: a full-width sticky bar with
the brand on the left and page links (Home, Findings, States, Method, Data)
on the right, plus a theme toggle and a hamburger menu on phones. The
header and footer are static HTML in the page template and the hand pages,
not built by JavaScript. The footer carries the same page links and no
badge.

## Headline result

Abia, 6 November 2026: display 4,062 = June 2021 4,062. Change 0 in every
LGA and every ward. Exact name repeats in 10 of 17 LGAs; missing numbers
only in Aba North (Ariaria Market 058, Eziama 057). Thirteen LGAs match
display names at every code; Osisioma Ngwa differs at 62 of 301 codes
(genuine: two 2021 readings agree against the display). Three LGAs are
settled with no single name verdict: Umuahia North (four name versions),
Aba North (five) and Aba South (six), because the portals returned
different name lists for the same codes on 6 November 2026; all versions
are published in the workbook. Ohafia and Osisioma Ngwa were recollected
on 6 November 2026; their ward 03s each returned three locator versions
in one day, all published.
